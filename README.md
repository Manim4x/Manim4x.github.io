# Sathyam Construction Website

Eco-friendly and sustainable construction company website.

Live demo: https://manim4x.github.io/

(Or after custom domain is connected: https://sathyamconstructions.net or whatever your domain is)

## About

This is a modern, responsive single-page website for Sathyam Construction — an eco-friendly builders company based in Tamil Nadu.

Features:
- Hero section with sustainable message
- Services grid (eco houses, hotels, hospitals, temples)
- About section highlighting planet-friendly construction
- Interactive quote request form
- Contact section
- Dark-mode friendly quote form with project type selection

Built with:
- HTML
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter & Poppins)
- Unsplash images

Data loaded from JSON files (services.json & portfolio.json)

## How to run locally

1. Download or clone this repository
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, etc.)
   - No installation or server needed — just double-click the file!
